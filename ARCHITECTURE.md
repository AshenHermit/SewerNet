# Архитектура SewerNet

## Общее описание
SewerNet — кастомный кроссплатформенный Matrix-клиент, ориентированный на расширяемость, кастомизацию, современный UI и простоту поддержки.

## Технологический стек
- Nx-monorepo
- Tauri
- React (Vite, Tailwind, shadcn/ui, zustand)
- NestJS
- lingui
- Next.js
- Docker-compose (prod)
- Github Actions

## Главные ценности
- Гибкая темизация и кастомизация
- Поддержка собственных скриптов и proxy-компонентов
- Прозрачность платформы для будущих платформ (mobile)

## Фокус прототипа
- web+desktop (mobile заложить архитектурно)
- Минимальный feature parity с Element
- Архитектура прокси-компонентов.

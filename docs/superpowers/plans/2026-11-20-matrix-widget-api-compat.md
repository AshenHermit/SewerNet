# Matrix Widget API Prototype-Freeze Compatibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore SewerNet Desktop UI and safe Tray Exit while keeping Tauri `freezePrototype: true`.

**Architecture:** Keep `matrix-js-sdk` version/API unchanged. Maintain a small npm patch for `matrix-widget-api` CommonJS export, and test the patched module in a child Node process whose `Object.prototype` is frozen. Remove ineffective Vite prebundle workaround; verify tray exit still follows JS coordinator and flushes before native exit.

**Tech Stack:** npm 11.6.1 / lockfile v3, Node test runner, Vite 8/Rolldown, Tauri 2, Rust.

**Spec:** `docs/superpowers/specs/2026-11-20-matrix-widget-api-prototype-freeze-design.md`

## Global Constraints

- Preserve `freezePrototype: true`.
- Keep Tray Exit path: `app-exit-requested` → JS coordinator → credential flush → `exit_desktop`.
- Do not update Matrix SDK major or change auth, storage format, draft confirmation, or exit semantics.
- Avoid manual edits to `node_modules`; patch must be reproducible from lockfile install.

## Review Focus

- Frozen inherited `Object.prototype.toString`: patched CJS module must load and expose callable own `toString` export.
- Patch reapplication on clean install: committed patch must be applied by repository's normal `npm ci` workflow.
- Tray event handling: confirm listener remains registered and coordinator does credential flush before `exit_desktop`.
- Patch scope: no unrelated generated bundle or SDK changes enter diff.
- Vite stale optimized cache: verify fresh desktop startup uses rebuilt dependency, not old generated cache.

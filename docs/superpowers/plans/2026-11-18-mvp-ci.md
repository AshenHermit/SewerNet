# MVP CI Baseline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Каждый PR и push в `master` проверяет все JS-проекты без secrets; landing действительно имеет typecheck.

**Architecture:** `ci.yml` вызывает reusable `checks.yml`. Начальный gate — весь JS workspace; desktop и Docker добавляют jobs в этот же reusable workflow своими планами. Проверки CI policy и build paths выполняются dependency-light Node tests.

**Tech Stack:** Nx 24, Node 24.11.0 (текущий проверяемый baseline), npm 11.6.1, GitHub Actions, Node test runner.

**Spec:** `docs/superpowers/specs/2026-11-18-mvp-polish-design.md`, sections 9, 11; индекс `2026-11-18-mvp-polish.md`.

## Global Constraints

- Команда общего gate: `npx nx run-many -t typecheck,lint,test,build`; non-watch CI режим. Native targets не требуют Windows toolchain в Linux job.
- Реальная default branch `master`; read-only CI permissions, forks без secrets, никакого выполнения PR через `pull_request_target`.
- npm root lockfile/workspaces; actions закреплять проверенными commit SHA с комментарием версии. Не менять Nx major/dependency stack ради CI.
- Allowlisted artifacts, без credentials/env/keys; task setup/branch/review — по общему индексу.

## Review Focus

1. Landing проверяется с чистого checkout до Next build, без `.next` — Task 1.
2. Target с watch defaults зависает в CI — Task 2.
3. Новый desktop target случайно попадает в Linux run-many — Task 2 contract и desktop Task 1.
4. Cache скрывает сломанную сборку или хранит приватный build — Task 2.
5. Fork PR получает write token или signing variables — Task 2.

**Files:** Modify `apps/landing/package.json`, при необходимости `apps/landing/tsconfig.json`; Create `tools/ci/workspace-policy.test.mjs`.

**Interfaces:** Consumes — root Nx graph. Produces — `landing:typecheck` (`tsc --noEmit -p tsconfig.json` с cwd `apps/landing`), root Node policy tests `node --test tools/ci/*.test.mjs`.

  ```js
  assert.ok(landing.targets.typecheck);
  assert.equal(landing.targets.typecheck.options.cwd, 'apps/landing');
  assert.match(landing.targets.typecheck.command ?? landing.targets.typecheck.options.command, /tsc.*--noEmit/);
  ```

### Task 2: Reusable JS CI gate и policy tests

**Files:** Create `.github/workflows/ci.yml`, `.github/workflows/checks.yml`, `tools/ci/workflow-policy.test.mjs`; Modify `package.json`, `package-lock.json`, `README.md`.

**Interfaces:** Consumes — Task 1 targets. Produces — reusable workflow `checks.yml` с `workflow_call`, job `javascript`, success обязателен для release; `ci.yml` triggers `pull_request`, push `master`, `workflow_dispatch`. Policy entrypoint остаётся `node --test tools/ci/*.test.mjs`.

- [ ] npm-командой добавить dev dependency YAML parser `yaml` для тестов. Написать `ci_policy_is_read_only`: assertions events/permissions, отсутствие `pull_request_target` и secret references; `checks_run_full_workspace_nonwatch`: exact command и `CI: 'true'`, Node `24.11.0`, npm `11.6.1`; `artifacts_are_allowlisted`: только web dist, landing output и test reports, без всего workspace; `cache_excludes_native_and_secrets`: npm download cache и `.nx/cache` только для unsigned JS checks, не `src-tauri/target`/release outputs.
  ```js
  assert.equal(ci.permissions.contents, 'read');
  assert.equal(checks.jobs.javascript.env.CI, 'true');
  assert.ok(checks.jobs.javascript.steps.some(s => s.run === 'npx nx run-many -t typecheck,lint,test,build'));
  assert.ok(!('pull_request_target' in ci.on));
  ```
- [ ] Выполнить `node --test tools/ci/*.test.mjs`. Expected: FAIL из-за отсутствующих workflow files.
- [ ] Создать workflows: checkout с полной историей для будущего tag ancestry gate, setup-node/npm ci, Node policy tests и полный Nx gate. GitHub permissions `contents: read`; concurrency на workflow/ref и cancel superseded PR runs; timeouts. Cache keys OS+Node/npm+lockfile+configs, untrusted PR caches не использовать в signed release. Test artifacts сохранять при failure только из test-output dirs; builds только из allowlist. До export landing artifact допускает `.next` без cache; deployment Task 1 меняет его на `out`.
- [ ] Выполнить Node policy tests, pinned actionlint (официальный Windows binary/проверенный checksum) для обоих YAML, `npm ci` и полный gate. Expected: PASS. В README записать команды JS/native separation; remote green CI до push/PR пока не доказана.
- [ ] Commit: `ci: add reusable workspace checks`.
